# Smart Retry 2.0 (browser demo)

Visual redesign of the Smart Retry MVP, a product challenge. **Unofficial prototype, not a Belvo product.**

Live demo: https://juanbustamanteg.github.io/smart-retry-2/ (users `operator` / `reviewer`, password `demo`).

Same rules, data and behavior as the original MVP (https://juanbustamanteg.github.io/belvo-smart-retry/); only the interface changed. Runs entirely in the browser (SQLite compiled to WebAssembly). This repository holds the static build only.
